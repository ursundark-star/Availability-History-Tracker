# Availability-History-Tracker
Tracking Project
🐳 Dockerized Python Availability App
A simple full‑stack Python application built with FastAPI (backend) and Flask (frontend), containerized using Docker Compose.
It allows users to manage weekly availability, name, city, and view their history — all stored in a SQLite database.

🚀 Features
Add weekly availability (e.g., Monday 10 AM – 5 PM)
Store and display Name and City
Track user activity history
Simple web interface built with Flask and Jinja2
Backend API powered by FastAPI
Fully containerized with Docker Compose
